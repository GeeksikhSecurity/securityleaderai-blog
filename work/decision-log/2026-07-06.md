## 1. Adopted AgentsView for session cost accounting (Simon Willison pattern)

**What changed:** tried Simon Willison's trick of running AgentsView *inside*
a remote Claude Code session to price it, and it works here:

```
uvx agentsview session usage <session-id> --json
```

arc: diagnosis → rebuild → R30 → merge → deploy → verification → handoff):

- Output tokens: **169,111**
- Peak context: **328,385**
- Estimated API-equivalent cost: **~$56.90** (claude-fable-5)
- Health grade: B (173 messages, 16 user turns, 1 tool failure, 0 compactions)

For scale: that bought a shipped production feature (5 posts with audio),
a build-failing integrity rule, the decision-log workflow itself, and the
ASVS resumption playbook.

**Adaptation into the workflow (not just a one-off):**
- CLAUDE.md → Decision Capture now requires recording session cost in the
  day's note before closing (cost is part of loop economics, per the token
  budgeting principle in the loop-engineering framework).
- `.claude/agents/decision-digest.md` → the end-of-day digest includes a
  Cost line when agentsview data is available, silent otherwise.

**Alternatives considered:** Simon's Claude Token Counter (web tool) for
per-document token counts — not adapted; it's a browser tool, and per-doc
token counts matter less to this project than per-session cost. Revisit if
we start budgeting individual posts for LLM processing.

**Verification:** `uvx agentsview --help` ran clean in-container (uv was
preinstalled; PyPI reachable through the proxy even though HuggingFace is
not), sync found this session, usage returned cost JSON.
